# Legal Watch Dog FE v0.9.0

## Release Date

June 9, 2026

## Summary

This release integrates the latest campaign geographic targeting controls and public blog guide discovery endpoints.

## Changed

### Campaign Geographic Targeting

- Added optional campaign setup fields for target countries and target states.
- Added optional runtime targeting for campaign content actions:
  - Run content generation.
  - Retry failed content.
  - Backfill missing content.
- Preserved global campaign behavior when no country or state scope is provided.
- Added campaign summary display for configured campaign scope.
- Added content pipeline metadata display for targeted runs when returned by the backend.

### Public Blog Guide Discovery

- Added public blog metadata API support:
  - Jurisdiction tree.
  - Country filters.
  - Topic filters.
- Added public blog search API support.
- Added country and topic filtering to the blog listing.
- Reworked the blog listing UI with:
  - Real-time search.
  - Country dropdown.
  - Topic dropdown.
  - Jurisdiction side rail tree.
  - Append-style pagination.
- Enhanced blog detail pages with:
  - Backend-provided breadcrumbs.
  - Related jurisdiction recommendation cards.

### Types And Tests

- Added typed campaign geo payloads and content pipeline metadata.
- Added typed public blog metadata, search, and recommendation contracts.
- Expanded API, store, and component test coverage for the new flows.
