# Super Admin Console

Back to the [manual index](./README.md).

## Who This Section Is For

This section is only for users with super admin access. Most end users should ignore this area.

The super admin console is a separate workspace used to operate the platform at a global level rather than inside one organization.

For the current step-by-step operating guide for campaign workflows and blog tools, continue to [Super Admin Campaigns and Blog Generation](./08-super-admin-campaigns-and-blog-generation.md).

## Main Areas

The navigation currently exposes:

- Overview
- Customers
- Blog
- Campaigns

## Overview

The Overview page acts as a platform dashboard. It can show:

- revenue information
- new users
- total users
- active users
- payment plan charts
- credit consumption charts
- recent users

Use this page when you need a fast snapshot of platform health and growth.

## Customers

The Customers area is designed for reviewing customer-level usage and account behavior. It includes:

- customer listing
- filters
- duration controls
- search
- payment status visibility
- activity and credit usage metrics

Use it when you need to:

- review customer activity
- find a specific customer
- compare user or payment patterns
- support account-level operations

## Blog

The super admin area includes blog tools. Based on the app structure, this area is meant for:

- viewing blog content
- generating or managing blog posts
- opening individual blog post pages tied to organizations and jurisdictions

This is an internal publishing or content-operations workflow, not a normal user feature.

## Campaigns

The Campaigns area is one of the more operational super admin modules.

It supports campaign work such as:

- viewing campaign lists
- filtering by organization, status, and industry
- creating campaigns
- opening campaign detail pages
- managing campaign taxonomy pages

Campaign statuses visible in the interface include states such as:

- draft
- taxonomy generation
- taxonomy ready
- hydrating
- discovering sources
- scraping
- publishing
- monitoring
- active
- paused
- completed
- failed
- cancelled

This suggests campaigns are long-running operational workflows rather than simple records.

## Super Admin Use Cases

- A platform operator checks revenue and growth trends.
- A support lead reviews customer activity and payment status.
- An operations user creates or inspects campaigns for an organization.
- A content operator manages blog generation workflows.

## Super Admin Caution

Because the super admin area has broader visibility and higher-impact controls, access should be limited to trusted operators only.
